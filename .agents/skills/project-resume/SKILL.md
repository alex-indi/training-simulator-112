# Project Resume

Продолжи работу без старого чата.

1. Определи корень Git и текущую ветку; посмотри `git status --short --branch`, `git log -5 --oneline --decorate` и diff незакоммиченных изменений.
2. Прочитай handoff в `tasks/`, если он есть для текущей ветки или старой задачи `UT112-XX`.
3. Прочитай `docs/current-state.md` и только те документы, которые нужны для этой работы.
4. Кратко сообщи, что сделано, что осталось и какой следующий шаг. Затем продолжай работу.

Не обращайся к WEEEK, не проси пользователя пересказывать старый чат, если состояние есть в Git, и не выполняй destructive Git-команды.
