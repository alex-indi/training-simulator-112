# Project Resume

Цель — продолжить работу без старого чата.

## Что сделать

1. определить корень Git;
2. посмотреть текущую ветку;
3. выполнить:
   ```bash
   git status --short --branch
   git log -5 --oneline --decorate
   ```
4. определить `UT112-XX` из фразы пользователя или имени ветки;
5. прочитать `tasks/UT112-XX.md`, если он есть;
6. прочитать `docs/current-state.md`;
7. прочитать только те документы, которые нужны именно этой задаче;
8. если WEEEK доступен — прочитать соответствующую задачу;
9. если есть незакоммиченные изменения — посмотреть diff;
10. коротко сообщить:
    - задача;
    - что уже сделано;
    - что осталось;
    - следующий шаг;
11. сразу продолжить работу.

Не проси пользователя пересказывать предыдущий чат, если состояние можно восстановить из репозитория.

Не выполняй destructive Git-команды.
