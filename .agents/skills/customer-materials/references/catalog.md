# Каталог материалов заказчика

## Назначение

Каталог помогает выбрать минимальное количество источников для конкретного
вопроса. Материалы не должны загружаться в контекст одновременно.

Путь к исходным файлам относительно каталога:

```text
../../../../materials/customer/
```

## Статусы обработки

- `NOT_REVIEWED` — содержимое ещё не изучено;
- `INDEXED` — структура документа изучена и описана;
- `PARTIALLY_REVIEWED` — изучена только часть документа;
- `REVIEWED` — документ изучен полностью;
- `SUPERSEDED` — заменён более актуальным источником.
