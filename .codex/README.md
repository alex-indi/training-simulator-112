# Codex setup

Общая конфигурация хранится в репозитории.

## WEEEK

Для MCP нужен `uv`:

```bash
uv --version
uvx --version
```

Скопируйте `.env.example` в `.env` и укажите:

```env
WEEEK_API_TOKEN=...
```

`.env` не коммитится.

В Codex проверить:

```text
/mcp
```

Если WEEEK временно недоступен, разработка продолжается через Git. Статус можно синхронизировать позже.

## Обычная работа

Пользователю не нужно помнить skills.

Достаточно фраз:

```text
Начни задачу UT112-XX
Сохрани состояние, продолжу на другом компьютере
Продолжи текущую задачу
Задача готова, проверь всё
```

Codex сам использует внутренние skills.
