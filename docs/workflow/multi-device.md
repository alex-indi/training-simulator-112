# Работа на нескольких устройствах

## Главный принцип

Проект между компьютерами переносится только через Git.

```text
компьютер A → commit → push → pull → компьютер B
```

Рабочую папку не переносим вручную.

## Перейти на другой компьютер

На текущем устройстве сказать Codex:

```text
Сохрани состояние, продолжу на другом компьютере
```

После успешного push на другом компьютере:

```bash
git fetch --all --prune
git switch <нужная ветка>
git pull --ff-only
```

Затем сказать:

```text
Продолжи текущую задачу
```

## Если Codex завис

Открыть новую сессию в той же папке и сказать:

```text
Продолжи текущую задачу
```

Старый чат не требуется.

## Если работа ещё не закоммичена

Новая Codex-сессия должна увидеть локальный `git diff` и продолжить с него.

Но перед физическим переходом на другой компьютер изменения обязательно нужно commit + push.
