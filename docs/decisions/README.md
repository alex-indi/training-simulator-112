# Architecture Decision Records

Крупные архитектурные решения оформляются отдельными ADR.

Формат имени:

```text
ADR-001-foundation.md
ADR-002-<short-name>.md
```

Минимальная структура ADR:

- Status: PROPOSED | ACCEPTED | SUPERSEDED;
- Context;
- Decision;
- Consequences;
- Alternatives considered;
- Related UT112 tasks.

`docs/decision-log.md` используется для более лёгких продуктовых и инженерных решений, которые не требуют полноценного ADR.
