## Проект

«Учебный тренажер 112», идентификатор `UT112`.

Два разработчика, несколько устройств Windows/macOS. Git remote — единственный канал передачи рабочего состояния.

## Основной обучаемый

Диспетчер ДДС получает готовую карточку, проверяет её, принимает/отклоняет и сопровождает реагирование своей службы.

Не путать его с оператором Службы-112, который формирует первичную карточку.

## Последние подтверждения заказчика

21.09.2026 заказчик уточнил:

- после принятия карточки используются доступные средства связи;
- решение о реагировании принимает диспетчер при наличии полномочий, иначе руководство;
- старший группы реагирования докладывает в ДДС о ходе работ;
- либо диспетчер сам звонит старшему и уточняет состояние;
- для тренажера ограничиваемся телефоном;
- внутренний процесс каждой службы свой;
- состав оповещаемых ДДС учитывает район обслуживания и подчинённость объекта.

## Решение команды для MVP

Телефонная коммуникация пока моделируется встроенным текстовым чатом.

Виртуальная группа реагирования:

```text
назначение
→ подтверждение задачи
→ выезд
→ прибытие
→ работы
→ завершение
```

Группа меняет своё состояние и присылает сообщения, но не меняет статус ДДС автоматически.

Обучаемый должен самостоятельно интерпретировать сообщения и обновлять карточку.
