## Цель

Добавить минимальную модель пользователей локального демонстрационного стенда с ролями `ADMIN`, `INSTRUCTOR` и `TRAINEE` без промышленной аутентификации.

## Сделано

- Задача назначена Александру Гордееву и переведена в `В работе`.
- Пройден Git-gate и создана отдельная ветка поверх готовой зависимой ветки UT112-4.
- Прочитаны критерии WEEEK, текущее состояние, продуктовые роли и архитектура.
- Добавлены SQLAlchemy-модель `User` и централизованный enum `UserRole` для `ADMIN`, `INSTRUCTOR`, `TRAINEE`.
- Добавлена миграция `20260922_01`, создающая таблицу `users` и трёх demo-пользователей.
- Добавлены API `GET /api/users/demo` и `GET /api/users/me`; текущий demo-пользователь определяется backend по заголовку `X-Demo-User`, по умолчанию используется `trainee`.
- Добавлены database dependency, session factory в lifespan и CORS для локального Vite frontend.
- Frontend получил переключатель demo-пользователя и отдельное содержание интерфейса для каждой роли.
- README дополнен описанием локального механизма выбора пользователя без промышленной аутентификации.
- Миграция применена к локальной PostgreSQL; API и все три роли проверены реальными запросами.
- В браузере проверено переключение интерфейса для `TRAINEE`, `INSTRUCTOR` и `ADMIN`.
