# UT112-42.4 — Подключение обучаемых и запуск

## Что делаем

Автоматически распределяем подключённых обучаемых по группам занятия, показываем готовность и при запуске материализуем общий или личный пул из утверждённых карточек.

## Сделано

- WEEEK #1371 назначена Александру Гордееву и переведена в «В работе».
- Создана ветка `feature/UT112-42.4-connect-and-launch` от реализации UT112-42.3.
- При подключении `TrainingRun` автоматически получает группу занятия по постоянной `UserGroup`; при отсутствии совпадения остаётся нераспределённым.
- Преподаватель видит АРМ, может изменить группу в рамках занятия и получает ready-check по группам на четвёртом шаге.
- При запуске общий утверждённый набор становится одной очередью группы; для личного пула каждому `TrainingRun` копируется полный набор snapshots и событий с отдельными runtime ID без AI.
- Live Monitor показывает группу каждого АРМ.
- Партии карточек всегда используют разные подходящие объекты; при нехватке объектов генерация сообщает причину. Сложность карточек берётся из группы занятия.
- Ручной перенос до запуска меняет только `TrainingRun.group_id`; runtime-параметры группы применяются при запуске.
- В редакторе группы можно перегенерировать тексты выбранных черновых карточек. Преподавательский интерфейс скрывает технические названия экземпляров и статусы.
