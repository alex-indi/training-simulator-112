# tasks/

Здесь Codex хранит короткое состояние **незавершённых задач**.

Пользователю обычно не нужно редактировать эти файлы вручную.

Для задачи:

```text
UT112-12
```

используется:

```text
tasks/UT112-12.md
```

В файле хранятся только:

- цель;
- что сделано;
- что осталось;
- проверки;
- блокеры;
- один следующий шаг;
- последний commit/push.

Не хранить здесь длинные обсуждения, полную документацию или логи.

Codex обновляет файл автоматически при командах:

```text
Сохрани состояние
Продолжи текущую задачу
```
