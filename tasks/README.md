# tasks/

Здесь Codex при необходимости хранит короткое состояние **незавершённой работы** перед паузой или сменой компьютера. Для небольших правок handoff не обязателен.

Пользователю обычно не нужно редактировать эти файлы вручную.

Для старой задачи:

```text
UT112-12
```

используется:

```text
tasks/UT112-12.md
```

Для новой работы без номера можно использовать файл с именем ветки, например `tasks/codex-fix-card-preview.md`.

В файле хранятся только:

- цель;
- что сделано;
- что осталось;
- проверки;
- блокеры;
- один следующий шаг;
- последний commit/push.

Не хранить здесь длинные обсуждения, полную документацию или логи.

Codex обновляет файл при командах:

```text
Сохрани состояние
Продолжи текущую задачу
```
