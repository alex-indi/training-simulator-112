# UT112-31.14 — единый локальный launcher

## Что делаем

Расширяем существующий `dev.py`: диагностика окружения, синхронизация зависимостей, проверка PostgreSQL и Alembic, безопасный запуск и контроль готовности сервисов.

## Сделано

- Задача назначена в WEEEK и переведена в «В работе».
- Создана ветка `feature/UT112-31.14-dev-launcher` от актуальной `main`.
- `dev.py` проверяет файлы, инструменты, Git, `.env`, зависимости, PostgreSQL, Alembic, справочники и порты; затем ждёт готовности обоих сервисов.
- Добавлены `--check`, `--verbose`, `--non-interactive`, `--skip-sync`, `--seed-demo`, `--open` и строгая проверка main.
- Добавлен fingerprint package-lock и регрессионный тест обновления зависимостей при существующем node_modules.
- README обновлён для запуска одной командой.

- `python -m unittest discover -s tests -p 'test_dev_launcher.py' -q` — пройден.
- Тот же тест с подменой на прежнюю проверку существования каталогов — ожидаемо падает (red/green).

- Полный `python dev.py --check --non-interactive` на чистой временной БД: миграции, CORE seed, порты — пройден.
