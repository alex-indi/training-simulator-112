# UT112-42.1 — Постоянные группы и подготовка занятия

## Что делаем

Добавить преподавателю постоянные группы обучающихся на основе `UserGroup` и выбор этих групп при подготовке занятия без подключённых АРМ и `TrainingRun`. Упростить первый шаг мастера согласно `docs/instructor-preparation-workflow.md`.

## Сделано

- Задача WEEEK #1368 назначена Александру Гордееву и переведена в «В работе».
- От `docs/UT112-43-cleanup` создана ветка `feature/UT112-42.1-persistent-groups`.
- Изучены текущие `UserGroup`, `TrainingGroup`, API и мастер занятия.
- Добавлены поля постоянной группы, связь `TrainingGroup.source_user_group_id` и миграция Alembic.
- Добавлен API преподавателя для списка, поиска через UI, состава, создания, правки и архивирования групп; использованная группа не удаляется физически через admin API.
- В кабинете появился раздел «Группы обучающихся» и шаг «Группы» сразу после создания занятия. Поддерживаются выбор существующих групп, создание третьей в модальном окне, сложность и общий/личный пул без АРМ.
- Первый шаг сокращён до названия, режима, параметров потока и порядка карточек. Класс перенесён после шага карточек.
